============================================================
RESEND EMAIL DELIVERY (OPTIONAL, RECOMMENDED)
============================================================
Set these as real environment variables (Apache SetEnv / Windows env /
Heroku config). NEVER commit the real API key.

Local XAMPP shortcut:
  paste the key into config/resend.local.php (gitignored) instead of setting
  a Windows/Apache environment variable. Environment variables win when set.

RESEND_API_KEY=re_xxxxxxxxx
RESEND_FROM_EMAIL=verify@your-verified-domain.tld
RESEND_FROM_NAME=CSDP LMS

Local testing only:
RESEND_TEST_TO=delivered@resend.dev
EMAIL_VERIFICATION_DEV_LOG=1

Notes:
1. Verify the sending domain in the Resend dashboard (SPF/DKIM) before
   using its address as RESEND_FROM_EMAIL.
2. delivered@resend.dev is a sandbox recipient: the API succeeds but no
   inbox receives the message.
3. EMAIL_VERIFICATION_DEV_LOG=1 writes the registration code to
   logs/email_verification.log (blocked from the web by logs/.htaccess).
   Never enable it in production.
