NOTES
===============================================================================

1. The base dump defines several relationship columns as varchar(255), including
   tbl_team.league_id, tbl_team.user_id, tbl_player.team_id, and tbl_schedule.winner.
   They are shown as inferred relationships because no foreign key constraints are
   declared for them in the base SQL dump.

2. The scheduling migration changes tbl_schedule.league_id, team_a, team_b, date,
   time, a_score, and b_score to stronger numeric/date/time types. This document
   uses the migrated schema for tbl_schedule.

3. Some migrations use bracket syntax, for example [tbl_league], which is not
   standard MySQL syntax. Their intended columns are still included because the
   application and base dump reflect those additions.
